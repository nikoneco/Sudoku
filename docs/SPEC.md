# 数独 v1 仕様

人間が考えたいところだけ考えられる数独。候補整理・Naked Singleのみ自動化し、Hidden Single、Pair、Locked Candidatesなどの推理はユーザーが行う。

合意事項: 有効候補は表示ON/OFFに関係なく合法候補から手動除外を引く。手動メモ1個だけでは確定しない。DEL操作（数字削除・メモクリア）では連鎖確定しない。表示設定変更も確定を起こさない。数字入力・候補の追加削除では連鎖を行う。

誤入力を拒否せず、正解盤で採点しない。衝突の視覚表示だけ行い、候補ゼロでも落とさない。1操作と自動連鎖を1回でUndo/Redo。固定数字は不変。

トップに続き・4難易度・設定・成績。途中問題は1件、新規開始で確認なしに置換。初期化失敗時は旧ゲームを保持。クリア済みを避けランダム、直前の問題を避ける。統計は問題置換で消さない。

iPhone縦画面最優先。盤面下の千鳥数字キー、MEMO/DEL/Undo/Redo。盤面同一セルの短いダブルタップでモード切替、行列ブロックの色と文字でモードを明示。同じ確定数字も強調。候補は固定3x3位置。

同じ数字の強調は薄紫。行列ブロックの青緑（MEMO時は橙色）と分ける。選択セルと衝突の赤表示を優先。手動で記入した候補メモの橙色は誤りを意味しない。

トップとプレイは完全な別画面とし、横並びの常設パネルは使わない。トップの装飾的キャッチコピーは置かず、SUDOKU・つづき・4難易度・設定・成績に絞る。

Vanilla JS + IndexedDB + Service Worker。GitHub Pages /Sudoku/ で配信。GAS/Sheetsは読取用問題DB。初回起動用の自作問題集も同梱し通信障害に備える。クライアントにsolutionを配信しない。Dailyは未実装、拡張用フィールドのみ保持。

完了基準: 主仕様の自動テスト、一意解全件検証、保存再開・Undo/Redo・オフラインのブラウザ確認、Pages/GAS公開確認。iPhone実機のインストール・standaloneは実機未接続なら未確認と報告する。
