# 数独 v1 仕様

人間が考えたいところだけ考えられる数独。候補整理・Naked Singleのみ自動化し、Hidden Single、Pair、Locked Candidatesなどの推理はユーザーが行う。

合意事項: 有効候補は表示ON/OFFに関係なく合法候補から手動除外を引く。手動メモ1個だけでは確定しない。DEL操作（数字削除・メモクリア）では連鎖確定しない。表示設定変更も確定を起こさない。数字入力・有効候補が変わる候補操作で連鎖を行う。理論上不可能なメモの追加削除では連鎖しない。

誤入力を拒否せず、正解盤で採点しない。衝突の視覚表示だけ行い、候補ゼロでも落とさない。1操作と自動連鎖を1回でUndo/Redo。固定数字は不変。

入力済みの編集可能マスへMEMOで数字を入れると、確定を解除して「元の数字＋押した数字」のメモへ変換する（例: 1→MEMO 9で1・9）。手動確定・自動確定の両方が対象。同じ数字なら1候補メモ。表示ON/OFFで同じ結果とし、理論上不可能な数字もメモ表示する。この変換では再自動確定せず、1Undoで確定状態へ戻る。固定数字は対象外。

トップに続き・4難易度・設定・成績。途中問題は1件、新規開始で確認なしに置換。初期化失敗時は旧ゲームを保持。クリア済みを避けランダム、直前の問題を避ける。統計は問題置換で消さない。

数字をDELしたマスは手動メモ・手動除外を両方リセットし、現在の盤面から合法候補を再計算する。他のマスのメモは保持。自動候補表示OFFでは候補は表示せず、ONに戻すと再計算した候補を表示する。DELでは候補が1個でも自動確定しない。Undoは数字と削除前のメモ情報をまとめて復元する。

iPhone縦画面最優先。盤面下の千鳥数字キー、MEMO/DEL/Undo/Redo。盤面同一セルの短いダブルタップでモード切替、行列ブロックの色と文字でモードを明示。同じ確定数字も強調。候補は固定3x3位置。

同じ数字の強調は薄紫。行列ブロックの青緑（MEMO時は橙色）と分ける。選択セルと衝突の赤表示を優先。手動で記入した候補メモの橙色は誤りを意味しない。

設定でクラシック・フォレスト・ローズ・ナイトの4テーマを選択し端末に保存。テーマごとに全体配色を変え、同数字・関連セル・選択・衝突・MEMOの区別を保つ。候補消去ボタンの有無でもモード表示行の高さは一定とし、パッド以下を動かさない。

MEMOのパッドは現在表示されるメモにある数字だけ背景あり、ない数字は背景なし。理論上不可能でも1〜9を自由に追加・削除できる（固定マスは除く）。表示ONは自動合法候補と手動メモの和、OFFは手動メモのみ、どちらも手動除外を優先する。手動メモは理論上不可能になっても保持する。数字入力モードは盤面に9個以上ある数字を背景なし・入力不可とし、キーボードも同じ制限にする。9個未満の誤入力は従来どおり可能。

数字入力で入力できるキーにはテーマのアクセント系ハイライト背景・枠・文字色を付ける。入力できないキーだけ背景なし。MEMOは候補登録状態のハイライトを維持する。

トップとプレイは完全な別画面とし、横並びの常設パネルは使わない。トップの装飾的キャッチコピーは置かず、SUDOKU・つづき・4難易度・設定・成績に絞る。

完成時はゲーム画面と盤面を残し、盤面中央の小さなレイヤーに「CLEAR」「難易度 時間」と「ホームへ」を表示する。×またはEscapeで閉じて盤面を見返せる。「ホームへ」でトップに戻る。完成後は時計と編集を停止し、再読み込みでも盤面と結果を復元する。成績は重複加算しない。

Vanilla JS + IndexedDB + Service Worker。GitHub Pages /Sudoku/ で配信。GAS/Sheetsは読取用問題DB。初回起動用の自作問題集も同梱し通信障害に備える。クライアントにsolutionを配信しない。Dailyは未実装、拡張用フィールドのみ保持。

Googleログインは任意。Firebase AuthenticationのGoogleログインと、数独専用Firestoreを使用する。同期は成績（クリア済み問題・難易度・ベストタイム）のみ。途中盤面・メモ・履歴・設定は端末内に保存し、クラウドへ送らない。別端末の同一問題は重複加算せず、既知の最短時間を残す。旧版で問題ごとの時間がない成績はクリア済みIDと難易度別ベストを保持する。

ゲストと各Googleアカウントの成績は端末内でも別管理。ログインだけでゲスト成績は送信しない。「この端末の成績を取り込む」で現在のアカウントへ移し、別アカウントへの再取り込みを防ぐ。ログアウト後はゲスト成績を表示。アカウント切替中の古い同期結果を別アカウントへ反映しない。オフラインでも遊べ、成績は端末に保存してオンライン復帰時に再同期する。再読込した完成盤面を別アカウントへ再計上しない。

完了基準: 主仕様の自動テスト、一意解全件検証、保存再開・Undo/Redo・オフラインのブラウザ確認、Pages/GAS公開確認。iPhone実機のインストール・standaloneは実機未接続なら未確認と報告する。
